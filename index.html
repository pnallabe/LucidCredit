The Reliability Stack

Built-In Trustworthiness

Three enforcement layers that make hallucination structurally impossible.

CitationEnforcer

Every generated claim is matched against retrieved chunks via embedding similarity. No citation — no claim. Enforced at inference time, not post-hoc.

ConfidenceScorer

Claims below the confidence threshold are stripped from the response and logged to the audit trail — creating an immutable record of every suppressed statement.

ECOA / SR 11-7 Compliance

ECOA adverse action notices and SR 11-7 model governance disclosures enforced at inference time — regulatory language is generated from verified templates, never synthesized.

Get Running

Start in Under 5 Minutes

Docker or local — your choice. Everything else is handled.

1
Clone and enter the project
git clone https://github.com/swarnabale/lucidcredit.git
cd lucidcredit
2
Copy the environment template and fill in your Azure OpenAI keys
cp .env.example .env
# Edit .env — at minimum set AZURE_OPENAI_ENDPOINT and AZURE_OPENAI_API_KEY
3
Start all services
Starts db, redis, copilot-api, and copilot-ui in the background
docker compose up -d
4
Apply database migrations
docker compose exec copilot-api alembic upgrade head
5
Ingest the regulatory and model card corpus
docker compose exec copilot-api python scripts/ingest_corpus.py
6
Open the UI — you're live
open http://localhost:3010
# API docs: http://localhost:8090/docs
1
Enter backend directory and create a virtual environment
cd backend
python3.11 -m venv .venv && source .venv/bin/activate
2
Install dependencies and load environment
pip install -r requirements.txt
set -a && source ../.env && set +a
3
Apply migrations and start the API server (hot-reload)
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8090
# → http://localhost:8090/docs
4
In a new terminal — install and start the frontend
The frontend proxies all /api/* requests to http://localhost:8090
cd frontend
npm install
npm run dev
# → http://localhost:3090
